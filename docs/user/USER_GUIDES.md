# PODX beta user guides

## Buyer
Choose a saved/manual location and radius, then search or browse categories. Open a product to compare nearby listing price, stock, distance, and freshness; confirm details with the shop because beta data is mocked. Use Watchlist and Alerts for local demo tracking. If unavailable, submit a product request. Open a shop to follow it. Use Profile for notification preferences, Privacy Center, consent and deletion controls, and Beta feedback.

## Seller
Enter through the seller area, complete the demo shop profile/location, and wait for the displayed verification state. Add an existing catalog product or request one, then update price and stock carefully. Review buyer requests and submit a demo response, create offers where enabled, and use Insights/Analytics for mock demand summaries. Plans and payments are demonstrations only. Privacy and support controls are available from seller/profile areas.

## Admin
Use only the assigned demo role. Review seller evidence and status, catalog/product requests, moderation reports, and support cases; provide a reason for sensitive changes. Review audit records after actions. Never treat mock revenue, subscription, verification, or security data as authoritative.
